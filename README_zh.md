# RainExtract

一个适用于雨课堂考试平台的油猴（Tampermonkey）用户脚本。本脚本主要为个人使用而开发。我在 macOS 的 Microsoft Edge（ScriptCat）以及移动端 Chromium 内核浏览器上测试通过；理论上可在任何兼容的系统与浏览器上运行。

现有的部分插件也能导出考试内容，但输出往往过于冗长，或生成图片堆砌、链接外置导致离线无法打开的 DOC 文件。RainExtract 是一个轻量级、零依赖的工具，满足我自己的需求：一键展开全部答案解析、把当前页面的所有试题保存为**真正的二进制 `.docx` 文件**，以及一键批量导出课程内所有已完成的试卷。

RainExtract 仅支持新版考试页面。尝试兼容旧版页面未能成功，且旧版页面已有多个成熟插件——有的擅长生成图片丰富的 DOC，有的 Markdown 导出做得不错，无需重复造轮子。

本脚本完全免费，禁止转卖。

## 功能特性

- **一键展开/收起**全部主观题答案解析
- **保存试题**为真正的二进制 `.docx` 文件（而非改名 HTML）
- **批量导出**（课程页）：下载全部已完成且可查看的试卷，支持试卷版 / 答案版 / 双版，可保存为独立 ZIP 或合并为一个 DOCX
- **手机端支持** — 支持手机网页版课程页与手机端考试/结果页，并通过 `show_paper` 接口解析真实考试名称与文件名
- **Material Design 3 界面** — 药丸按钮、单选控件、对话框、进度条与 Snackbar，含状态层与键盘焦点环
- 可拖拽悬浮面板，自动贴边吸附，支持折叠为悬浮球动画
- 在考试页与结果页之间自动切换状态。考试进行页仅导出题目，不支持展开解析

> **重要提醒**
> 
> 在 iOS 设备上使用时，实测可能会遇到以下问题：
> - 保存带图片试卷速度非常缓慢
> - 批量提取试卷界面获取试卷信息速度非常缓慢
> - 由于保存带图片试卷速度缓慢，导致批量保存会失败
> 
> 以上问题暂时无法解决，建议批量保存或保存带图片试卷时优先使用其它类型设备以获得更好的体验。
> 
> 虽然已经增加保存进度以优化 iOS 设备在考试页面或考试结果界面保存带图片试卷时的体验，但批量保存时大概率失败。如必须使用 iOS 设备批量保存，建议在批量保存页面取消保存带图片试卷，并单独在考试结果页面进行保存。

## 导出的 DOCX 说明

由自研 ZIP/CRC32 + OOXML 引擎在本地构建——**无 CDN、无 npm、无 JSZip、构建时无任何网络请求**。

- 正文：宋体 / Times New Roman，小四（12 号）；标题：居中加粗，16 号
- 每张试题图片均以 `word/media/imageN.png|jpeg|gif` 的形式**打包进文件内部**（真正的内嵌对象——不是 base64 链接，不是外链 URL），文件 100% 离线可用
- 行内 MathJax `<svg>` 与 svg/webp data-URL 会先栅格化为 PNG；无法访问的图片降级为纯文本
- 选择题格式：

  ```
  1. 题干

  A. 选项
  B. 选项
  C. 选项
  ...

  答案：A
  ```

- 主观题格式：

  ```
  1. 题干

  答案：解析内容
  ```

简言之，导出文件不包含个人作答内容，只导出题目及教师提供的答案或解析。考试进行页仅导出题目信息。

## 安装

1. 安装一个用户脚本管理器，如 **Tampermonkey**、**Violentmonkey** 或 **ScriptCat**。
2. 打开最新 Release 页面，点击 `RainExtract.user.js` 安装脚本。
3. 访问 `www.yuketang.cn` 或 `examination.xuetangx.com`，脚本会自动运行。

## 使用方法

### 单卷保存（考试页 / 结果页）

- 点击**展开所有解析**显示全部答案解析，再次点击收起。
- 点击**保存所有试题**导出试卷版，或点击**保存答题试卷**导出答案版。
- 拖拽悬浮面板到任意位置，会自动吸附到最近的屏幕边缘。

### 批量导出（课程页）

1. 在电脑端打开课程页（`/v2/web/studentLog/...`）或手机端课程页（`/m/v2/course/normalcourse/logs/...`），面板会自动切换为批量模式。
2. 选择版本（试卷版 / 答案版 / 双版）与格式（ZIP 或合并 DOCX）。
3. 在确认弹窗中核对统计信息，然后确认。
4. 脚本会连续打开并自动关闭一系列考试标签页。**请先关闭浏览器的弹出窗口拦截或将域名加入白名单**，期间请勿操作浏览器，等待其结束。
5. 进度、错误与逐卷状态会在弹窗中实时显示；出错后弹窗保持打开，便于查看和复制错误列表。
