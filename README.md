# RainExtract

A Tampermonkey userscript for the Rain Classroom examination platform. This script was mainly built for personal use. I tested it with ScriptCat on Microsoft Edge for macOS and on mobile Chromium-based browsers; in theory it should run on any compatible system and browser.

Some existing plugins can export exam content, but their output tends to be overly verbose, or they produce image-heavy DOC files and remote-URL links that break offline. RainExtract is a lightweight, zero-dependency tool that meets my own needs: viewing all answer explanations at once, saving all questions on the current page as a **real binary `.docx` file**, and batch-exporting every finished exam in a course in one click.

RainExtract supports the new exam page layout only. Attempts to support the old layout were unsuccessful, and there are already several solid plugins for it — no need to reinvent the wheel.

This script is completely free and must not be resold.

## Features

- **One-click expand/collapse** for all answer explanations
- **Save exam questions** to a real binary `.docx` file (not a renamed HTML)
- **Batch export** from the course page: download all finished & viewable exams as paper version / answer version / both, as individual ZIP files or one merged DOCX
- **Mobile support** — works on the mobile web course page and mobile exam/result pages, including real exam titles and filenames resolved from the `show_paper` API
- **Material Design 3 UI** — pill buttons, radios, dialogs, progress bar and snackbars, with state layers and keyboard focus rings
- Draggable floating panel with auto edge-snapping and collapse-to-ball animation
- Automatically switches state between the exam page and the results page. On the live exam page, only questions are exported; explanation expansion is not available.

## The exported DOCX

Built locally by a self-written ZIP/CRC32 + OOXML engine — **no CDN, no npm, no JSZip, no network at build time**.

- Body text: SimSun / Times New Roman, size 12; title: centered, bold, size 16
- Every question image is packed **inside** the file as `word/media/imageN.png|jpeg|gif` (true embedded objects — not base64 links, not remote URLs), so the file is 100% offline
- Inline MathJax `<svg>` and svg/webp data-URLs are rasterized to PNG first; unreachable images degrade to plain text
- Multiple-choice questions:

  ```
  1. Question stem

  A. Option
  B. Option
  C. Option
  ...

  答案(Answer, Chinese only): A
  ```

- Subjective questions:

  ```
  1. Question stem

  答案(Answer, Chinese only): explanation content
  ```

In short, the exported file does not include personal responses. It only exports questions together with the teacher-provided answers or explanations. On the live exam page, only question information is exported.

## Installation

1. Install a userscript manager such as **Tampermonkey**, **Violentmonkey**, or **ScriptCat**.
2. Open the latest release page and click `RainExtract.user.js` to install the script.
3. Visit `www.yuketang.cn` or `examination.xuetangx.com`, and the script will run automatically.

## Usage

### Single exam (exam / result page)

- Click **Expand All Explanations** to show all answer explanations; click again to collapse.
- Click **Save All Questions** to export the paper version, or **Save Answered Paper** for the answer version.
- Drag the floating panel to any position; it snaps to the nearest screen edge.

### Batch export (course page)

1. Open a course page on desktop (`/v2/web/studentLog/...`) or mobile (`/m/v2/course/normalcourse/logs/...`). The panel switches to the batch mode automatically.
2. Pick a version (paper / answer / both) and a format (ZIP or merged DOCX).
3. Review the statistics in the confirmation dialog, then confirm.
4. A series of exam tabs will open and close automatically. **Disable the pop-up blocker or whitelist the domain first**, and do not operate the browser until it finishes.
5. Progress, errors and per-exam status are shown live in the modal; the dialog stays open on failure so you can inspect and copy the error list.
