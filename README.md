# RainExtract
A Tampermonkey userscript for the RainC examination platform. This script was mainly built for personal use. I tested it with ScriptCat on Edge 27 for macOS and Haitai Browser 7 for HarmonyOS, both Chromium-based browsers, and it works fine. In theory, it should run on any compatible system and browser. I also added a small toggle animation for the floating button.

Some existing plugins can export exam content, but their output tends to be overly verbose. So I built a lightweight tool that meets my own needs: viewing all answer explanations at once and saving all questions on the current page. I have only tested it with multiple-choice and subjective questions. Image-based and true/false questions are not yet covered due to lack of samples, but they should be supported in theory and may be added later if needed.

RainExtract supports one-click expansion of all subjective-question explanations and saving all questions on the current page to a file. It only supports the new exam page layout. Attempts to support the old exam page layout were unsuccessful, and there are already several solid plugins for it. Some of those plugins produce image-heavy DOC outputs, while others handle Markdown export reasonably well, so there is no need to reinvent the wheel.

This script is completely free and must not be resold.

## Exported DOC Content Reference
Body text uses SimSun, size 12.

Exam page title: centered, size 16.

Multiple-choice questions:
1. Question stem
A. Option
B. Option
C. Option
...
答案(Answer, Chinese only): A

Subjective questions:
1. Question stem
答案(Answer, Chinese only): explanation content

In short, the exported DOC file does not include personal responses. It only exports questions together with the teacher-provided answers or explanations. On the live exam page, only question information is exported.

## Features
- One-click expand/collapse for all answer explanations
- Save exam questions to a file
- Draggable floating button with auto edge-snapping
- Automatically switches state between the exam page and the results page. On the live exam page, only questions are extracted, and explanation expansion is not available.

## Installation
1. Install a userscript manager such as **Tampermonkey**, **Violentmonkey**, or **ScriptCat**.
2. Open the latest release page and click `RainExtract.user.js` to install the script.
3. Visit `examination.xuetangx.com`, and the script will run automatically.

## Usage
- Click the “Expand All Explanations” button to show all answer explanations.
- Click it again to collapse all explanations.
- Use the “Save All Questions” button to export questions to a file.
- Drag the floating button to any position; it will snap to the nearest screen edge. The expansion state updates automatically when switching between the exam and results pages.

## Requirements
- A Chromium-based browser or Firefox
- A userscript manager such as Tampermonkey, Violentmonkey, or ScriptCat
