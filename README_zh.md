# RainExtract
一款用于 RainC 考试平台的 Tampermonkey 用户脚本。主要是为了自用而做出来的，我用的是脚本猫（MacOS 27 Edge/HarmonyOS7 海泰浏览器）测试没有问题，这两款都是Chromium浏览器，理论上支持任何符合条件的系统和浏览器，顺便加了个悬浮窗切换小动画，之前有些插件能导出但文件输出内容比较多，所以根据自己的需求做了一个查看所有解析和保存所有题目的工具，只测试了选择题和主观题，图片和判断题还没有样本，但理论上支持，如果后续遇到了可能会更新支持。RainExtract支持一键展开所有主观题解析以及保存当前页面的全部试题。仅支持新版考试页面，旧版考试跟千问斗智斗勇失败了，同时也有一些做的不错的支持旧版考试的插件，而且全是图片效果变成doc不是很好，有的功能能转换成md格式还可以，就不重复造轮子了。生成后的文件内容可以直接打印成纸质试卷复习，格式基本适配考试宝等平台的规则，雨课堂内其实理论上也可以直接上传生成后的试题导入成考试，避免浪费大量时间在调整文字格式上。本脚本完全免费使用，不得倒卖。

## 导出doc文件内容参考（正文字体为宋体小四）：
考试页面标题（小二居中）
选择题：
1.题干
A.选项
B.选项
C.选项
...
答案：A
主观题：
1.题干
答案：（解析内容）
一言以蔽之，导出的doc文件不包含个人作答情况，只导出题目和老师给出的答案或解析。若在考试中界面则只有题目信息。
## 功能
- 一键展开/折叠所有答案解析
- 将试题保存到文件
- 可拖动的浮动按钮，支持自动贴边吸附
- 在考试页面与考试结果页面会自动切换状态，考试页面仅提取题目，同时不支持展开解析功能（本来也没有）

## 安装
1. 安装用户脚本管理器，例如 **Tampermonkey**、**Violentmonkey** 或 **ScriptCat**。
2. 打开最新版本发布页面，点击 `RainExtract.user.js` 安装脚本。
3. 访问 `examination.xuetangx.com`，脚本将自动运行。

## 使用方法
- 点击展开所有解析按钮展开所有答案解析。
- 再次点击可折叠所有答案解析。
- 使用保存所有试题按钮将试题导出到文件。
- 可将拖动悬浮按钮，自动吸边，在考试和考试结果页切换会自动切换展开状态。

## 运行要求
- Chromium 内核浏览器或 Firefox
- 用户脚本管理器，例如 Tampermonkey、Violentmonkey 或 ScriptCat
