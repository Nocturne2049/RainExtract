# RainExtract
A Tampermonkey userscript for the RainC examination platform. RainExtract lets you expand or collapse all answer explanations with one click and save exam questions to a file. A draggable floating button with auto edge-snapping is included.
## Features
- One-click expand/collapse for all answer explanations
- Save exam questions to a file
- Draggable floating button with auto edge-snapping
- Automatic state switching on SPA page navigation
## Installation
1. Install a userscript manager such as **Tampermonkey**, **Violentmonkey**, or **ScriptCat**.
2. Open the latest release page and click `RainExtract.user.js` to install the script.
3. Visit `examination.xuetangx.com` and the script will run automatically.
## Usage
- Click the floating button to expand all answer explanations.
- Click it again to collapse all explanations.
- Use the save button to export exam questions to a file.
- Drag the floating button to any position on the page.
## Requirements
- A Chromium-based browser or Firefox
- A userscript manager such as Tampermonkey, Violentmonkey, or ScriptCat
